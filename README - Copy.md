# 🔒 Locked-In

> **Desktop prisoner job management system built for the Tlokweng Correctional Facility**

Locked-In is a second-year **Systems Analysis and Design** university project created to replace the prison's manual job management process. The system connects community employers with prisoners who have the required skills, making it easier to advertise work opportunities, manage applications, and maintain accurate records.

The project was developed to apply the FAST systems development methodology while designing and building a solution for a real community need.

---

## ✨ Features

- 👤 Manage prisoner and employer records
- 💼 Create and manage job opportunities
- 🛠️ Match prisoners to jobs based on their skills
- 📝 Apply for available jobs
- 👮 Automatic guard allocation for job sites
- 📄 Generate reports and job records
- 🔐 Role-based user authentication

## 📖 How It Works

1. Employers post available jobs.
2. Prisoners browse jobs matching their skills.
3. Prisoners submit applications.
4. Employers review and approve applicants.
5. The system allocates guards and creates a job record.
6. Completed jobs are recorded for future reporting.
